# Icicle Twin

A digital twin of Microchip's PolarFire SoC Icicle Kit that runs in your browser. Nothing to install.

**▶ Open it: https://devonance.github.io/icicle-twin-site/**

[![Watch the 90-second video](https://img.youtube.com/vi/6G-Jhx50wdw/maxresdefault.jpg)](https://youtu.be/6G-Jhx50wdw)

Power the board on and watch signals light up the real copper, plug in peripherals, boot real RISC-V Linux
under QEMU, and run Doom on a simulated monitor. Built from Microchip's free, public board files.

This repository holds only the built site. Open source: Apache-2.0 code, CC BY 4.0 content, third-party parts
under their own licences (see the Credits page in the app; GPL sources are in `qemu/source/`).
