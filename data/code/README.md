# public/data/code (WP-03, M0-12)

Generated by `tools/content/extract_code.py`: 47 verbatim excerpts (each <= 60 lines), located by regular
expressions on the source so a moved line fails the build instead of copying the wrong text. Types:
`CodeIndexFile`, `CodeExcerptMeta`, `CodeExcerptFile` (src/core/types/data.ts).

Plus one rendered excerpt, `job-header-xml` (issue #122, group `FlashPro Express job`, language `xml`): the
FlashPro job's `header.xml`, which is a single 75 KB line, shown as selected elements one per line in file order
with the file's values, built from `public/data/jobfile` (facts only; no boundary-scan patterns, I/O states, build
paths or bitstream). Its line numbers are those of the rendering.

## index.json

`{schema: "icicle-twin/code-index@1", count, max_lines: 60, excerpts: CodeExcerptMeta[]}` where each entry has
`id`, `title`, `path` (upstream path), `repo`, `commit`, `licence`, `url` (with `#Lfirst-Llast`),
`language` (`c|h|dts|tcl|pdc|rst|ld|md|xml`), `file`, `firstLine`, `group` (`HSS|U-Boot|Linux|Libero|FlashPro Express job`),
`steps`, plus `end_line`, `source`, `lines` (count).

`commit`: the HSS / reference-design SHA; U-Boot `v2022.01`; Linux files were fetched from `master` on
2026-10-16 without a commit id, so `commit` reads `master@2026-10-16 (blob <sha1>)` and every excerpt keeps
the full git `blob_sha1` of its source file.

## <id>.json

`{schema: "icicle-twin/code-excerpt@1", id, firstLine, lines[], notes{ "<upstream line>": gloss }}` plus
`title`, `lang`, `repo`, `commit`, `path`, `start_line`, `end_line`, `url`, `blob_sha1`, `licence`,
`licence_basis`, `copyright`, `steps`, `note`, `highlights[{label, lines:[a,b]}]` (upstream line numbers).
A `CodeRef.lines` in a scenario uses upstream line numbers too.
