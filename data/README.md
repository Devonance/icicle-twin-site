# public/data: WP-03 board tables and memory map (M0-13)

Generated by `tools/content/extract_maps.py` (+ `board_tables.py`, `typed.py`). Every file has the core-v1
fields of `src/core/types/data.ts` (checked by `src/data/content.ts` guards and
`tests/unit/data/wp03-content.test.ts`) plus provenance fields. Board nets come from the IPC-D-356 netlist
that kicad-cli exported from the KiCad import of the Allegro board (`build/kicad/icicle.ipc`, git-ignored);
full net names are recovered from `icicle.kicad_pcb`, full refdes from `icicle-pos.csv`. Logs, job file and
code excerpts are documented in their own folders. `board/` belongs to WP-01.

Common header: `schema`, `generated_by`, `retrieved`, `sources` (id -> title, repo/url, commit, licence),
`netlist` (file, blob_sha1) where the netlist was used.

## memmap.json (`MemMapFile`)

`regions[]` (75, sorted by base, non-overlapping): core-v1 `id`, `name`, `base`, `size` (hex strings, no
separators), `kind` (`ram|nvm|mmio|window`), `owner` (block id, `U2` for DDR), `bus`, `source` (one line:
`<source> <file> L<line>; ...`). Extras: `category` (memory/peripheral/fabric/ddr-window), `end`,
`size_verified` (false = 4 KiB assumed), `size_basis`, `sim_unit`, `refdes`, `notes`, `sources[]` (each
citation with file, line and the base/size it gives), `verification`:

| verification | meaning | count |
|---|---|---|
| two-source | >= 2 independent projects (Linux dts, HSS, MPFS HAL, MSS configurator XML, reference design, docs) give the same base | 41 |
| two-source-contained | independent sources; the later ones lie inside the first range (eNVM 0x2022_0000 vs HSS link 0x2022_0100; demux window vs register 0x4FFF_FF00; DRI vs PCIe bridge regs) | 3 |
| two-file | two files of one project (TIMs: mpfs_reg_map.h + hss-l2scratch.lds) | 6 |
| single-source | one source only: unverified | 25 |

Also: `ddr_segments` (SEG registers decoded from the MSS XML next to the 2021 log values), `ddr_usage`
(Linux memory nodes, HSS payload reservation), `known_addresses` (load addresses printed in the logs),
`aliases` ('HI' peripheral aliases at +0x0800_0000), `reset_vectors`, `boot_mode`.

## pins.json (`PinsFile`)

`refdes: "U1"`, `pins[]` = all 484 U1 pads `{ball, net, port?, bank?, macro?, ioStandard?}`. Extras:
`design_io[]` (189 ports: PDC entry with file/line/direction/io_std/pull/schmitt/bank vcci, job BSR index and
macro, board net, `checks.net_vs_port`, `verification`), `mss_io_selected[]`.

## jumpers.json (`JumpersFile`)

`jumpers[]` (13): `id`, `pins` (2|3), `purpose`, `default` (GitHub guide; J9 = closed for the embedded
FlashPro6), `ugPdfDefault` (UG PDF Table 2-1 text, for the honesty card), `options[{setting, meaning}]`,
`source`. Extras: `pin_nets` (netlist), `github_default`, `github_text`, `ug_pdf_default`, `ug_pdf_text`,
`options_detail`; top-level `netlist_checks` (J34/J35/J43 pin nets prove 2-3 = 1.8 V / 2.5 V / Bank-4).

## interrupts.json (`InterruptsFile`)

`interrupts[]` (18): `F2M_0..10`, `F2M_59..63`, `GPIO2_INT_30/31` with `number`, `source` (README), `target`
(`PLIC n`), `note`. Extras: `f2m[]` with `plic` = F2M + 118 (stated by the dts for F2M 1, 4, 59-62; inferred
for the rest), `buttons`, `sw4`, `mss_peripherals[]` (PLIC numbers from mpfs.dtsi), `gpio_irqmux`.

## gpio2.json (`Gpio2File`)

`base`, `bits[]` (25 from the README table): `bit`, `name`, `dir` (`io|out|in`), `ball`, `net`, `rpiName`,
`note`; extras `port`, `rpi_pin`, `board_led`, `colour`, `linux_label`, `readme_line`.

## rpi-header.json (`RpiHeaderFile`)

`refdes: "J26"`, `pins[]` (40): `pin`, `name`, `kind` (`power|gnd|gpio|i2c|spi|uart|id|nc`), `net` (J26
pad net), `ball`, `port`, `gpio2Bit`, `fabricAddress`; extras `connection` (README text), `rpi_name`.

## mikrobus.json (`MikrobusFile`)

`refdes: ["J44","J8"]`, `pins[]` (16): `pin` (mikroBUS name), `net`, `ball`, `mss` (`SPI1_SCK`,
`MMUART4_TX`, ...); extras `socket`, `pin_number`, `signal`, `port`, `peripheral`, `via`.

## uart-map.json (`UartMapFile`)

`uarts[]` (5): `id`, `name`, `base`, `txBall`, `rxBall`, `txNet`, `rxNet`, `cp2108Interface`, `console`
(`COM_A..D`), `testPoints {tx, rx}` (UG Table 2-3), `role`; extras `plic`, `tx`/`rx` (port, CP2108 pin, series
resistor). `test_points[]` with the TP nets and `test_points_note` (the TPs sit on CP2108 toggle nets).

## power-rails.json (`PowerRailsFile`)

`rails[]` (12): `rail`, `regulator`, `part`, `input`, `probe` (UG Table 1-4 capacitor), `nominalV`,
`tolerancePct`, `led`; extras `probe_ug`, `probe_on_rail_in_netlist`, `regulator_candidates`, `regulator_basis`.
`regulator_io` (every regulator's input/outputs inferred from the netlist), `indicator_leds`, `ld_leds`,
`ug_regulators` (UG Table 2-5), `pac1934`.

## clocks.json (`ClocksFile`)

`clocks[]` (7: X2, X4, X5, U32, Y4, Y5, Y3 DNP): `refdes`, `part`, `hz`, `kind`, `rail`, `nets`,
`destination` (IC pins reached through at most one series part); extras `pin_nets`, `destinations[]`,
`bom_description`, `do_not_load`. Top-level `dts` (refclk 125 MHz, refclk_ccc 50 MHz, scbclk 80 MHz), `ug`.
